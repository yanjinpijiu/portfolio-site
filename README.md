# 个人简历站（demo 版）

给正在求职的同学：把项目讲清楚的一页简历站——简历 PDF 之外，再给 HR 一个能继续往下看的地址。

- **在线 demo**：<https://profile.qianlink.top>（示例数据，后台演示密钥 `demo`，只读）
- **技术栈**：Vue 3 + Vite · Java 21 + Spring Boot · H2（文件模式）· Nginx
- **一键部署**：Docker Compose（`cp .env.example .env` → 改两个值 → `docker compose up -d`）
